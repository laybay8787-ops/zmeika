# 🐍 Змейка — Веб-игра

Современная веб-игра «Змейка» с управлением с клавиатуры и сенсорного экрана.

## 🚀 Как запустить локально

### Шаг 1: Установите Node.js

Вам нужен **Node.js** версии 18 или выше.

- Скачайте с [nodejs.org](https://nodejs.org/) (рекомендуется LTS-версия)
- После установки проверьте в терминале:
  ```bash
  node --version
  npm --version
  ```
  Обе команды должны вывести номер версии.

---

### Шаг 2: Распакуйте ZIP-архив

Распакуйте скачанный ZIP-файл в удобную папку, например:
- Windows: `C:\Users\ВашеИмя\snake-game\`
- macOS: `~/snake-game/`
- Linux: `~/snake-game/`

---

### Шаг 3: Откройте терминал

**Windows:**
- Откройте папку проекта в Проводнике
- В адресной строке Проводника введите `cmd` и нажмите Enter
- Или: Shift + правый клик в папке → «Открыть окно PowerShell здесь»

**macOS:**
- Откройте Terminal
- Введите `cd ` (с пробелом после cd), затем перетащите папку проекта в Terminal и нажмите Enter

**Linux:**
```bash
cd ~/snake-game
```

---

### Шаг 4: Установите зависимости

В терминале выполните:
```bash
npm install
```

Это создаст папку `node_modules` (может занять 1–3 минуты).

---

### Шаг 5: Запустите игру

**Вариант A — Режим разработки (с автоперезагрузкой):**
```bash
npm run dev
```
Откройте в браузере: **http://localhost:3000**

**Вариант B — Продакшн-сборка:**
```bash
npm run build
```
Готовые файлы появятся в папке `dist/`.

## ❓ Частые проблемы

**«npm не найден»**
→ Установите Node.js с [nodejs.org](https://nodejs.org/)

**«Порт 3000 уже используется»**
→ Закройте другие приложения, использующие порт 3000, или измените порт в `vite.config.js`

**Белый экран в браузере**
→ Откройте консоль браузера (F12) и проверьте ошибки. Убедитесь, что выполнили `npm install`

**Сборка не проходит**
→ Удалите папку `node_modules` и файл `package-lock.json`, затем снова выполните `npm install`
